# Préversions Android de VEILLE

Ce dépôt distribue des **préversions Android destinées aux tests**. Le code source de l’application VEILLE est privé ; ce dépôt contient uniquement les fichiers publiés dans les [Releases](https://github.com/Axellpz13/veille-android-releases/releases) et leurs empreintes de contrôle.

## Version publiée

[VEILLE Android 0.2.0 — bêta interne 1](https://github.com/Axellpz13/veille-android-releases/releases/tag/v0.2.0-beta.1) comprend un fichier APK et son fichier `.sha256`. La page de la version précise les appareils compatibles et les limites de cette préversion.

**État du test :** l’envoi SOS réel est désactivé dans cette version, selon ses notes de publication. Cette application ne remplace pas les services d’urgence.
